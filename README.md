# DeutschBot

تطبيق محلي بسيط لممارسة اللغة الألمانية للمبتدئين الناطقين بالعربية. يحتوي على درس تعارف من أربع خطوات بإجابات وقواعد مُعدّة مسبقاً؛ لا يستخدم ذكاءً اصطناعياً أو واجهات API مدفوعة أو مفاتيح أو تبعيات.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث. أو شغّل خادماً محلياً مجانياً من مجلد المشروع، مثلاً إذا كان Python مثبتاً:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. قد تتطلب ميزة الميكروفون بيئة آمنة مثل localhost أو HTTPS ومنح إذن الميكروفون. يختلف دعم التعرّف على الكلام بين المتصفحات، وقد تعتمد هذه الميزة على خدمة المتصفح واتصال الإنترنت؛ تبقى الكتابة متاحة عند عدم دعمها. النطق يعتمد على أصوات المتصفح والنظام المثبتة.

اكتب إجابتك بالألمانية واضغط Enter أو «إرسال». استخدم زر الاستماع لسماع رسالة ألمانية، ومفتاح الترجمة لإظهار العربية أو إخفائها، وزر السهم الدائري لبدء الدرس مجدداً. تحفظ نسبة التقدم على الجهاز في `localStorage`، وليس سجل المحادثة؛ عند العودة يستأنف الدرس من الخطوة المحفوظة. إعادة البدء تصفّر التقدم.

## الملفات

- `index.html`: بنية الواجهة.
- `style.css`: التصميم المتجاوب والرسوم والحركة.
- `script.js`: الدرس والقواعد والتقدم وميزات الصوت.
