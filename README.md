# DeutschBot

تطبيق محلي بسيط لممارسة اللغة الألمانية للمبتدئين الناطقين بالعربية. يحتوي على درس تعارف من أربع خطوات بإجابات وقواعد مُعدّة مسبقاً؛ لا يستخدم ذكاءً اصطناعياً أو واجهات API مدفوعة أو مفاتيح أو تبعيات.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث. أو شغّل خادماً محلياً مجانياً من مجلد المشروع، مثلاً إذا كان Python مثبتاً:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. قد تتطلب ميزة الميكروفون بيئة آمنة مثل localhost أو HTTPS ومنح إذن الميكروفون. يختلف دعم التعرّف على الكلام بين المتصفحات، وقد تعتمد هذه الميزة على خدمة المتصفح واتصال الإنترنت؛ تبقى الكتابة متاحة عند عدم دعمها. النطق يعتمد على أصوات المتصفح والنظام المثبتة.

اكتب إجابتك بالألمانية واضغط Enter أو «إرسال». استخدم زر الاستماع لسماع رسالة ألمانية، ومفتاح الترجمة لإظهار العربية أو إخفائها، وزر السهم الدائري لبدء الدرس مجدداً. تحفظ نسبة التقدم على الجهاز في `localStorage`، وليس سجل المحادثة؛ عند العودة يستأنف الدرس من الخطوة المحفوظة. إعادة البدء تصفّر التقدم.

## الملفات

- `index.html`: بنية الواجهة.
- `style.css`: التصميم المتجاوب والرسوم والحركة.
- `script.js`: الدرس والقواعد والتقدم وميزات الصوت.

## التحقق اليدوي

شغّل التطبيق على localhost أو HTTPS، ثم اختبر الإجابات وإعادة تحميل الصفحة للتأكد من حفظ التقدم. جرّب إلغاء إعادة البدء وتأكيدها؛ التأكيد يعيد تقدم الدرس إلى الصفر. اختبر الميكروفون بإذن مسموح ومرفوض، والإيقاف أثناء الاستماع، وإرسال الإجابة أو تعديلها أثناء الجلسة. راجع النص المنطوق قبل إرساله. اختبر متصفحاً لا يدعم الصوت، والتنقل بلوحة المفاتيح، وعرض الهاتف. يعتمد الصوت على المتصفح وأذونات الجهاز والأصوات المثبتة.

في Chrome افتح أدوات المطوّر ثم Console، وفعّل عرض رسائل Verbose لرؤية تشخيص `[DeutschBot speech]`. ابدأ التسجيل وقل جملة ألمانية: يجب أن تظهر نتيجة مؤقتة ثم نهائية إن أرسلها المتصفح، دون إرسالها تلقائياً. تشير أحداث `audiostart` و`soundstart` و`speechstart` إلى مراحل مختلفة، ولا يعني `start` وحده أن الصوت وصل. لا يسجّل التشخيص نص الكلام. إذا لم تظهر نتيجة، افحص إذن الموقع، وميكروفون النظام، والاتصال بخدمة المتصفح؛ قد يتطلب التعرّف اتصالاً بالإنترنت.

## Hören & Sprechen

اختر أحد المواقف الثلاثة واستمع إلى كل سؤال بالسرعة العادية أو البطيئة، ثم اكتب الإجابة أو استخدم الميكروفون وراجع النص قبل التحقق. يقارن التطبيق عبارات بسيطة ويعرض مثالاً؛ لا يستخدم الذكاء الاصطناعي ولا يقيس النطق، وقد يرفض إجابة صحيحة لم تتضمن عبارة متوقعة. يمكن المحاولة مجدداً أو التخطي. يعرض زر «التالي» بعد الإجابة المقبولة. التقدم المحفوظ يحسب الجولات التي تم تجاوزها أيضاً، ويحفظ بشكل منفصل تحت `deutschbot-listening-speaking-v1` دون تغيير تقدم الدرس الأصلي. إعادة ممارسة موقف مكتمل لا تمحو تقدمه المحفوظ.

اختبر في المتصفح المواقف الثلاثة وجميع جولاتها، والإجابات البديلة وغير المطابقة، والمحاولة والتخطي والانتقال وإعادة الممارسة. أعد تحميل الصفحة وتحقق من حفظ كل موقف والتقدم الأصلي. اختبر إظهار الترجمة وإخفاءها، والتشغيل العادي والبطيء، ولوحة المفاتيح وعرض الهاتف. في Chrome على localhost أو HTTPS اختبر إذن الميكروفون ورفضه، وراجع النص قبل التحقق، وعدّله أثناء الاستماع، وانتقل بين المواقف والدرس أثناء التسجيل أو التشغيل. تحقق أيضاً من الكتابة ورسائل الدعم في متصفح لا يدعم الصوت. يعتمد التعرف على دعم المتصفح وقد يحتاج إلى الإنترنت.

واجهة `conversationEngine.evaluate` غير المتزامنة تستقبل الموقف والجولة والإجابة وتعيد القبول والتعليق والمثال. يمكن مستقبلاً تنفيذ واجهة مماثلة لخادم Ollama محلي مع معالجة الأخطاء والخصوصية وإبقاء القواعد المحلية بديلاً؛ لا يوجد اتصال بـ Ollama حالياً.
